### 💡 About Me

I design and build enterprise software at the intersection of **modern web applications**, **device tooling**, and **system automation**.

My primary focus is developing custom solutions with **SharePoint Framework (SPFx)** and modern TypeScript. I build backend tooling and automation utilities using **Python**, **C#**, **PowerShell**, and occasionally **Rust**. My integration work centers around enterprise platforms like **SafeQ** and **M-Files**.
